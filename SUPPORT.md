# Getting support

The fastest way to get a useful answer is to choose the right place.

| I want to... | Go to |
|---|---|
| Ask how to use something, or share an idea | [Discussions](https://github.com/paulnewmandev/pn-ultramemory/discussions) |
| Report a reproducible bug | [Bug report form](https://github.com/paulnewmandev/pn-ultramemory/issues/new?template=bug_report.yml) |
| Request a feature | [Feature request form](https://github.com/paulnewmandev/pn-ultramemory/issues/new?template=feature_request.yml) |
| Report a security problem | [SECURITY.md](SECURITY.md). Never in a public issue. |
| Understand how it is built | [docs/architecture.md](docs/architecture.md) and [docs/glossary.md](docs/glossary.md) |
| Contribute a change | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Report a Code of Conduct concern | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Before you ask

1. Read the [README](README.md), and check the [CHANGELOG](CHANGELOG.md) for your version.
2. Search existing issues and discussions.
3. Run `pn-ultramemory --version` and note your operating system.

## A good bug report contains

- The version and operating system.
- What you did, what you expected, and what happened.
- The smallest repository or command that reproduces it.
- Relevant output, with secrets removed.

This is a volunteer-maintained project. Response times vary, and clear reports with a small
reproduction are answered first.
