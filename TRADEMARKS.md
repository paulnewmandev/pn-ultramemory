# Trademark and naming policy

The **code** of this project is licensed under [Apache-2.0](LICENSE), which lets you use, modify,
redistribute and sell it. A license to the code is **not** a license to the name. This page says
what you may do with the name, so that a person who downloads something called
"pn-ultramemory" knows what they are getting.

This is a small open-source project, not a company with a legal department. These are the
maintainers' expectations, written plainly.

## Always allowed, no permission needed

- Saying that your product, article, video, course or tool **uses**, **works with**, **supports**
  or **is compatible with** pn-ultramemory.
- Writing about the project, reviewing it, criticizing it or teaching it, under any name.
- Using the name in the technical identifiers you need: package names on a registry you are
  publishing a genuine build to, `pn-ultramemory` in a command line, a configuration key, an
  import path, a Docker tag, or a repository named `pn-ultramemory-<something>` for an extension.
  Technical identifiers are not branding.
- Distributing **unmodified** builds under the project name, including in a package manager.
- Forking the project, as Apache-2.0 allows. See the next section for what to call the fork.

## Ask first

- Naming a **modified** version "pn-ultramemory", or a name so close that a user would think it is
  this project. Call it something else, and say plainly that it is *based on* or *a fork of*
  pn-ultramemory. This is the whole point of the policy: a user who hits a bug should know whose
  bug it is.
- Using the name or the logo as the name or logo **of your own product**, company or service.
- Suggesting that the maintainers endorse, sponsor, certify or support you, or that your build is
  "official".
- Registering the name, or a confusingly similar one, as a trademark or a domain that looks
  official.

## The logo

The marks in [`assets/logo/`](assets/logo/) may be used to refer to the project: in an article, a
talk, a comparison table or a "works with pn-ultramemory" badge. Do not modify them beyond
scaling, do not use them as the logo of your own product, and do not imply endorsement.

## Marking

The maintainers do not currently claim a registered trademark. The name is marked as an
unregistered mark where it is used as a brand. There is no need to add any symbol when you follow
this policy.
